# 못깨는 타워 (2D 도전 타워) — 설계 문서

작성일: 2026-11-25 / 상태: 승인 대기
기준 문서: `2026-11-19-gimkit-energy-game-design.md` (에너지·퀴즈·기록·모바일 세로·전체 화면 규칙)

## 1. 의도
대상 학생들이 로블록스의 "어려운 타워 오르기"(타워 오브 헬 계열, 흔히 '잼못타'로 불리는 장르)를 좋아한다. **익숙한 형식이고 도전정신을 자극한다**는 점이 이 게임을 만드는 이유다. 그래서 장르의 핵심 재미(한 구간씩 오르는 긴장감, 체크포인트 없는 아슬아슬함, 판마다 달라지는 변형, "이번엔 깬다"는 재도전 욕구)를 살리고, 이 앱의 정체성(퀴즈로 에너지 충전)과 자연스럽게 묶는다.

조사로 확인한 것(출처는 개요/위키 수준, 실제 플레이 영상은 못 봄): 구간 8개를 무작위로 쌓아 시간 안에 체크포인트 없이 오르는 방식, 파생작은 물 차오름·손 떨림·무너짐·무중력·점프력 변화 같은 규칙 변형을 붙임. 정확한 원작 규칙을 복제하지 않고 장르 규칙만 가져온다.

## 2. 목표 / 비목표 / 안티목표
**목표**
- 2D 세로 타워를 구간별로 오르는 새 게임 1개 (게임 id `obby`, 시작 화면 타일 5번째)
- "한 번에 못 깬다" 수준의 도전 난이도 + 그래도 "다음엔 깰 수 있겠다"고 느끼게 하는 공정함
- 에너지/퀴즈를 **도전권**으로 연결(아래 §4), 기록(최고 구간/클리어 시간) 저장
- 점프맵과 같은 조작(왼쪽 조이스틱 + 오른쪽 점프, 이단 점프)으로 즉시 익숙하게

**비목표**: 3D(three.js), 멀티플레이/온라인 랭킹, 로블록스 맵·이름·그림 복제, 점프맵 규칙 변경.
**안티목표**: 운으로만 깨지는 구간, 풀 수 없는 구간, 실패가 너무 답답해서 포기하게 만드는 경험(진행도·이번 판 최고 구간을 항상 보여 줌), 퀴즈가 점프 도중 끼어드는 것.

## 3. 접근 방식
- 2D 세로 타워(채택): 점프맵의 이동·충돌 물리(`js/games/jump/world.js`의 `stepPlayer`)와 장애물 요소(움직이는/얼음/컨베이어/부서지는 발판, 가시, 스프링, 바람)를 재사용. 새 폴더 `js/games/obby/`.
- 점프맵의 "도전 모드"로만 추가: 빠르지만 별개 게임 느낌이 약해 제외.
- 3D: 설치 파일(600KB), 폰 조작·성능·그래픽 부담으로 제외.

## 4. 게임 규칙 (제 판단, 수치는 시작값)
- **타워 구성:** 구간 8개 + 꼭대기 골. 구간은 미리 설계한 패턴 모음에서 난이도 단계(쉬움 → 보통 → 어려움)에 맞춰 판마다 무작위로 뽑아 쌓는다(1~2구간 쉬움, 3~5 보통, 6~7 어려움, 8 마지막 관문). 같은 판 안에서 같은 패턴은 반복하지 않는다.
- **구간 패턴:** 장르에 맞는 장애물 조합(좁은 발판 건너기, 움직이는 발판 타이밍, 얼음 위 정확한 정지, 컨베이어 역주행, 부서지는 발판 연속 점프, 가시 사이 통과, 스프링으로 높이 올라가기, 바람 속 점프). 각 패턴은 데이터로 작성하고 **풀 수 있음을 자동 검증**한다(점프 시뮬레이션으로 입구에서 출구까지 경로 탐색, 테스트로 보장).
- **실패와 재도전:** 떨어지면(화면 아래/가시/변형 효과) 그 판(도전)이 끝난다. 다음 도전을 시작할 때 에너지 ⚡ 1을 쓴다(**에너지 = 도전권**, 최대 5). 0이면 퀴즈로 충전(정답당 +2, 연속 정답 보너스, 기존 방식)한 뒤 도전한다. 퀴즈는 도전 사이에만 열려 점프 도중 끊기지 않는다.
- **모드(시작 시 선택):** `연습` — 2개 구간마다 체크포인트 깃발(밟으면 다음 도전이 그 구간에서 시작, 변형 없음). `못깨는` — 체크포인트 없음, 떨어지면 처음부터, 변형 효과 1개 적용.
- **변형 효과(못깨는 모드, 판마다 1개 무작위):** 🌊 물 차오름(아래에서 천천히 올라옴, 닿으면 실패), 🤝 손 떨림(화면과 조작이 약하게 떨림), 🪶 무중력(중력 약함), ⏱ 점프력 변화(10초마다 점프 높이 ±25%, 남은 시간 표시), 🧱 무너짐(모든 발판이 밟으면 곧 부서짐), 💨 바람(옆으로 계속 밀림). 시작할 때 효과 안내 문구가 뜬다. 구간 패턴은 어떤 변형에서도 깰 수 있게 여유를 둔다.
- **클리어:** 꼭대기 골 깃발에 닿으면 클리어(축하 장면, 걸린 시간, 도전 횟수). 시간제한 없음(압박 대신 기록 단축 도전).
- **기록:** 최고 도달 구간(1~8)과 최단 클리어 시간을 기기에 저장. 결과 화면에 이번 도전 구간·최고 구간 표시.
- **화면/조작:** 점프맵과 동일(전체 화면, 상단 HUD 아래 우측 기록 박스에 "구간 N/8"과 도전 횟수, 에너지 표시). 이름은 임시로 "못깨는 타워"(변경 가능).

## 5. 구조와 에이전트 분업
- `js/games/obby/world.js`(구간 조립·변형 효과·충돌/실패 판정, 점프맵 물리 재사용), `sections.js`(패턴 데이터 약 24~36개 + 검증용 풀이 탐색), `index.js`(그리기·게임 연결), 테스트 `tests/obby-*.test.js`.
- 1단계: 패턴 데이터와 풀이 검증기(에이전트 1). 2단계: 게임 본체와 변형 효과·기록·결과 화면 연결(에이전트 2, 1단계 결과 사용). 3단계: 브라우저 검수와 난이도 조정.
- 시작 화면: 픽셀 아이콘 추가, 타일 5개(2열 3행). 신규 게임의 도전권 에너지는 `energyMax: 5`.

## 6. 검증
- 패턴 풀이 검증기 테스트(모든 패턴이 시뮬레이션으로 클리어 가능), 구간 조립(난이도 단계, 중복 없음) 테스트, 변형 효과 단위 테스트.
- 브라우저: 모바일 크기 플레이, 변형별 화면, 실패→퀴즈→재도전 흐름, 클리어 장면.
- 난이도 체감은 실제 플레이로만 확인 가능하다(자동 검증은 "풀 수 있는지"까지). 출시 후 조정 상수(변형 세기, 구간 난이도 배치)는 한 곳에 모은다.

## 7. 빌더에게 맡기는 부분
패턴 구체 배치, 색상·장애물 그림, 효과음 조합(기존 sfx 이름), 변형 연출, 수치 미세 조정, 클리어 연출.

## 8. 제 판단으로 정한 것 (확인 필요)
- 에너지를 점프마다가 아니라 **도전(시도)마다** 쓰도록 바꿈 → 점프 타이밍이 중요한 장르에서 퀴즈 끊김을 없앰.
- 시간제한 없음, 8구간, 연습/못깨는 두 모드, 변형 6종, 이름 "못깨는 타워"(‘잼민이’는 초등학생을 낮춰 부르는 속어라 앱 이름에는 쓰지 않음).
